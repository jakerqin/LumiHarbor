# 首页聚合

位置：[`routers/home/`](../../app/routers/home/)

`home_router` 合并：

- `featured.py` → `GET /home/featured`
- `timeline.py` → `GET /home/timeline`

## 精选照片墙

### 职责

返回当前用户**收藏**的素材列表，供 Bento / Dome Gallery 使用；不是「AI 评分精选」。

### 数据流

```text
user_favorites ⋈ assets
  filter: user_id + 双方 is_deleted=false
  order: favorited_at DESC
  limit: 默认 9，最大 150
  → 批量查 AssetTag
  → 用 asset_template_tags.template_type='home_featured' 过滤要返回的标签
  → 根据 aspect_ratio 分类 horizontal/vertical/square
  → FeaturedResponse
```

### 响应约定（例外）

**直接返回 `FeaturedResponse`**，不包 `ApiResponse`。字段带 camelCase alias（如 `userId`）。前后端联调时务必注意拦截器不会解包。

### 设计决策

用收藏表做精选数据源，让用户显式决定「首页看见什么」；模板 `home_featured` 控制卡片上暴露哪些元数据，避免把全部 EXIF 打到首页。

## 大事记时间轴

### 职责

`GET /home/timeline`：以 **Note** 为事件源做时间轴，不是 Asset 大事记。

### 行为要点

- Query：`limit`（默认 10）、`created_by`
- 响应：`ApiResponse[TimelineResponse]`（与 featured 不同，走统一壳）
- 封面信息来自笔记的 `cover_asset_id`

### 与旧文档差异

CLAUDE.md 曾写「前端 Mock / 后端待实现」。**后端 timeline 已实现**；若前端仍 Mock，属于前端未接线，不是后端缺失。

## 依赖

```text
featured → UserFavorite, Asset, AssetTag, AssetTemplateTag, AssetUrlProvider
timeline → Note (+ 封面 Asset URL)
```

## 已知限制

- 无 JWT；`user_id` / `created_by` 由客户端传入。
- featured 响应格式与项目统一约定不一致。
- 时间轴语义是「笔记叙事」，不是「相册旅程节点」；若产品要 Asset/Album 大事记，需要新接口或扩展数据源。
