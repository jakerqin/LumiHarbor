# 系统管理

位置：[`routers/management.py`](../../app/routers/management.py)

## 职责

提供轻量运维探针与库内素材计数，便于本地/容器探活。不做用户管理、不做任务重试控制台。

## 接口

前缀：`/management`

| 方法 | 路径 | 职责 |
|---|---|---|
| GET | `/health` | 探测数据库连通性 |
| GET | `/statistics` | 素材总数 / 图片数 / 视频数（未删除） |

## 设计说明

- `/health` 失败应返回非成功业务码或 HTTP 错误（以实现为准），供编排系统判断依赖是否就绪。
- 统计是简单 `COUNT`，没有缓存层；数据量很大时可加缓存或异步汇总表。

## 已知限制

- 不检查 Redis / Worker 是否存活（API 健康 ≠ 异步链路健康）。
- 无鉴权；勿直接暴露到公网而不加网关保护。
