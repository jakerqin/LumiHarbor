# 数据模型

位置：[`app/model/`](../../app/model/)

全局约束：

- **无数据库外键**、无 SQLAlchemy `relationship`
- 业务表默认带 `is_deleted`（`users`、`task_logs` 除外）
- 关联靠应用层 ID / `tag_key` + 索引

## 实体关系（逻辑）

```text
users ──created_by──▶ assets ◀── asset_id ── album_assets ── album_id ──▶ albums
  │                     │  ▲
  │                     │  └── cover_asset_id（albums / notes）
  │                     ├── asset_tags ── tag_key ──▶ tag_definitions
  │                     ├── user_favorites
  │                     └── task_logs
  └── notes

asset_template_tags ── tag_key ──▶ tag_definitions
metadata_dictionary（location_poi 等场景字典，独立）
```

## assets

文件：[`asset.py`](../../app/model/asset.py) · 表名 `assets`

| 分组 | 字段 |
|---|---|
| 归属 | `id`, `created_by` |
| 路径 | `original_path`, `thumbnail_path`, `preview_path` |
| 文件 | `asset_type`, `mime_type`, `file_size` |
| GPS 冗余 | `gps_latitude`, `gps_longitude`（地图聚合用，避免每次 JOIN 标签） |
| 哈希 | `file_hash`, `phash`, `dhash`, `average_hash`, `colorhash` |
| 权限/时间 | `visibility`, `shot_at`, `created_at`, `updated_at`, `is_deleted` |

索引：

- `idx_file_hash_not_deleted (file_hash, is_deleted)` — 去重
- `idx_original_path_not_deleted` — 路径查询（前缀长度限制）
- `idx_created_by_shot_at` — 用户时间线
- `idx_gps_location (gps_latitude, gps_longitude, shot_at)` — 足迹

**设计要点**：`preview_path` 给浏览器无法直接显示的格式（如 HEIC）用；四感知哈希字段配合加权相似度。

## albums / album_assets

[`album.py`](../../app/model/album.py)、[`album_asset.py`](../../app/model/album_asset.py)

相册核心字段：`name`, `description`, `start_time`, `end_time`, `cover_asset_id`, `visibility`, `created_by`, 时间戳, `is_deleted`。

- `start_time` / `end_time`：由 `AlbumService` 按关联素材 `shot_at` 自动维护
- `cover_asset_id`：可手动设置；为空时自动选最早 `shot_at` 素材
- 索引：`idx_time_range (start_time, end_time)`

关联表：`album_id`, `asset_id`, `sort_order`；唯一约束 `uk_album_asset`；索引 `idx_album_sort`。

## notes

[`note.py`](../../app/model/note.py)

| 字段 | 含义 |
|---|---|
| `content` | **主存**：Tiptap JSON（必填） |
| `content_markdown` | 列仍在；前端不再写入，列表摘要走 `build_excerpt` |
| `cover_asset_id` | 封面素材 |
| `related_assets` | JSON 列；**当前创建逻辑写死为 `None`，未维护** |
| `is_encrypted` | 加密标记（预留） |
| `shot_at` | 叙事发生时间（可与创建时间分离） |

这与早期「Markdown + `asset://` 主存」的产品文档不同——**以代码为准**。

## 标签与模板

| 表 | 作用 |
|---|---|
| `tag_definitions` | 全局定义：`tag_key` / `tag_name` / `input_type` / `extra_info` / `source` |
| `tag_mappings` | EXIF/FFmpeg 源键 → `tag_key` + `transform` |
| `templates` | kind=`ingest`/`detail`/`filter`/`card`，按 `asset_type` 可设默认 |
| `template_fields` | 模板下字段：`field_source`=`tag`/`asset`/`relation` |
| `asset_tags` | 素材取值 |
| `task_definitions` | 可关后处理：thumbnail / preview / phash / geocoding / batch_phash |
| `asset_template_tags` | 旧绑定表，ingest 模板缺失时回退 |

**为什么用 `tag_key` 而不是 `tag_id` FK**：导入热路径少一次查定义；跨类型复用；模板表达可选集合。

## task_logs

[`task_log.py`](../../app/model/task_log.py)

记录异步任务：`task_type`, `task_status`, `asset_id`, `task_params`, `retry_count`, `max_retries`, `error_message`, `executed_at`…

- **当前实际写入**：地理编码；发送 phash 时写 pending
- 开关见 `task_definitions` 与 `/tasks/definitions`

## users / user_favorites

[`user.py`](../../app/model/user.py)、[`user_favorite.py`](../../app/model/user_favorite.py)

- `users`：账号骨架（username/password_hash/role…），**尚无鉴权路由**
- `user_favorites`：`user_id + asset_id` 唯一；首页精选数据源；支持软删取消收藏

## metadata_dictionary

[`metadata_dictionary.py`](../../app/model/metadata_dictionary.py)

场景字典：`(scene_type, value)` 唯一。当前主场景是 `location_poi`，配合 Redis Set 缓存与素材筛选下拉。

## 改表时注意

1. 同步更新仓库根 [`scripts/init_db.sql`](../../../../scripts/init_db.sql)（项目规范）。
2. 新业务表加 `is_deleted`，除非明确是系统日志类表。
3. 不要引入数据库外键；补应用层校验与合适索引即可。
