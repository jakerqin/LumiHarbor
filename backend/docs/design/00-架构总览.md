# 后端架构总览

LumiHarbor（拾光坞）后端是一个 **FastAPI + SQLAlchemy + Taskiq** 的个人生活素材管理系统 API。它负责素材导入、元数据/标签、相册与笔记、首页聚合、地图足迹，以及耗时任务（感知哈希、地理编码）的异步执行。

三条事实值得先记住：

- **Router 是薄入口**。HTTP 参数校验与响应包装在路由层；业务编排在 `services/`；持久化与纯计算分别落在 `model/` 与 `tools/`。
- **导入是主链路**。扫描/上传最终都走 `AssetImportService`：哈希去重 → 入库 → 标签/缩略图/预览 → 异步 phash / geocoding。
- **统一响应壳是默认契约**。绝大多数接口返回 `{code, message, result}`；当前唯一已知例外是 `GET /home/featured`（直接返回业务对象）。

## 分层怎么分工

```text
run.py / uvicorn
    └── app/main.py                 FastAPI 入口：CORS、静态媒体、异常、路由注册
            ├── routers/            HTTP 边界（薄）
            ├── services/           业务编排与领域逻辑
            │   ├── ingestion/      导入主链路
            │   ├── metadata/       EXIF / ffmpeg 提取
            │   ├── thumbnail/      缩略图
            │   ├── preview/        HEIC 等预览图
            │   └── tags/           标签映射与模板过滤
            ├── model/              SQLAlchemy 表模型（无 FK）
            ├── schema/             Pydantic 请求/响应 + ApiResponse
            ├── tasks/              Taskiq + Redis 异步任务
            ├── tools/              哈希、感知哈希等纯工具
            ├── config/             pydantic-settings
            └── db.py               Engine / Session / get_db
```

## 一条导入请求经过什么

```text
POST /ingestion/scan 或 /ingestion/upload
        │
        ▼
FilesystemScanner / 临时目录文件
        │
        ▼
AssetValidator（SHA256 smart hash + 去重）
        │
        ▼
LocalNasStorage（规划路径 / 必要时复制进 NAS）
        │
        ▼
写入 assets（shot_at、gps_* 冗余字段）
        │
        ▼
AssetProcessor
  ├─ 元数据 → MetadataTagMapper → TagService（模板过滤）
  ├─ ThumbnailGenerator（WebP）
  ├─ PreviewGenerator（仅 HEIC/HEIF）
  └─ 异步任务
        ├─ calculate_phash（无 task_logs）
        └─ calculate_location（写 task_logs，可重试）
        │
        ▼
（可选）AlbumService 关联相册
```

## 与产品文档的关系

- `CLAUDE.md` / `AGENTS.md` 面向协作与快速上手，会滞后于代码。
- **本目录以当前 `backend/app` 源码为准**。已知与旧文档不一致之处，已写进各模块「已知限制 / 与文档差异」小节。
