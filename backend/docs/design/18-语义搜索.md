# 语义搜索

补「红衣服 / 海边日落 / 静安寺那次」这类话。成员墙已经覆盖「找某人」，phash 覆盖「长得像哪张」。不搜笔记/相册，不恢复 Spotlight。

## 职责边界

- **负责**：素材图文向量、导入后异步写入、`GET /assets?q=` 混合排序
- **不负责**：OCR、笔记/相册混搜、替换 phash、路人聚类

关键文件：

- 编码：[`tools/clip.py`](../../app/tools/clip.py)
- 入库 / 补算：[`services/clip.py`](../../app/services/clip.py)
- 检索：[`services/search.py`](../../app/services/search.py)
- 任务：[`tasks/clip_tasks.py`](../../app/tasks/clip_tasks.py)
- 向量：[`services/vector_store.py`](../../app/services/vector_store.py) collection `assets_clip`

## 模型

| 项 | 值 |
|---|---|
| 权重 | `google/siglip2-base-patch16-256`，本地 `CLIP_MODEL_DIR`（默认 `backend/models/siglip2`） |
| 维数 | 768 cosine |
| 文本 | `padding=max_length`，`max_length=64` |
| 标记 | `assets.clip_model = siglip2-base-patch16-256` |
| 粗筛 | `CLIP_MATCH` 默认 `0.045`（「绿草地」前三约 0.10/0.10/0.05，再往下约 0.03 不相关） |

和宠物 DINOv2 同为 768 维也**禁止**写入 `subjects_*`。换模型必须改 collection 或清空后全量 backfill。权重未就绪时查询只走词法，不 500。

### 并发与就绪（[`tools/clip.py`](../../app/tools/clip.py)）

- **推理串行**：所有 `get_text_features` / `get_image_features` 共用 `_infer_lock`。PyTorch MPS 后端不是线程安全的，API 同步接口在线程池里并发首推时会同时写 MPS shader 缓存（C++ `unordered_map`），哈希表被写坏后线程在 `MetalShaderLibrary::exec_unary_kernel` 里死循环、CPU 100% 且无法结束（2026-10 实测复现：启动后立刻并发 3 个搜索，1 个永久卡死）。
- **加载即预热**：加载线程在设置「就绪」前先跑一次文本推理，把 shader 编译好；预热失败则整体视为加载失败，不留半成品全局。
- **查询最多等 5 秒**（`QUERY_WAIT_SECONDS`）：明显小于前端 10 秒超时，等不到就只走词法，不让请求挂过前端超时。

推理图路径对齐人脸：`preview > original > thumbnail`；视频用预览帧，音频跳过。

## 写入

导入 [`processor.send_async_tasks`](../../app/services/ingestion/processor.py) 在 `compute_clip` 开关打开时：TaskLog → `compute_clip_task.kiq`。

运维：`POST /management/clip/backfill` `{missing_only, limit, asset_ids?}`。

软删素材时删 `assets_clip` 对应点。

## 查询

`GET /assets` 增加可选 `q`。空：现列表逻辑不变。

有值时：

1. 文本 → SigLIP 2 → Qdrant `search(limit=80, score_threshold=CLIP_MATCH)`
2. 词法各取约 40：`original_path` / `location_*` / `subjects.name`（经未删除 `faces`）
3. RRF：`score = Σ 1/(60+rank)`，同分再按 `shot_at desc`
4. 再套现有筛选后分页

不要手调 CLIP 原始分与词法加权。

## 已知限制

- Worker 再加载一个视觉模型，本机 `WORKER_COUNT` 建议仍为 1。API 启动时后台加载并预热文本塔；第一次搜索若还在加载最多等 5 秒，超时只走词法（这期间翻页可能前后排序不一致）。
- 不懂专有名词——人名、小地名靠词法。
- 视频只看一帧预览。
- 不搜笔记/相册；不恢复 Cmd+K。
