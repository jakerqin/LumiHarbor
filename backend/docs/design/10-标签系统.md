# 标签系统

## 职责边界

- **负责**：全局标签定义查询；导入时把 EXIF/FFmpeg 映射为 `tag_key`；按模板过滤后写入 `asset_tags`
- **不负责**：地理编码本身（见 [异步任务](./15-异步任务.md) / `location.py`）；素材列表 UI 展示逻辑

关键文件：

- Router：[`routers/tags.py`](../../app/routers/tags.py) — `GET /tags/definitions`
- Service：[`services/tags/service.py`](../../app/services/tags/service.py)
- Mapper：[`services/tags/mapper.py`](../../app/services/tags/mapper.py)
- Models：`tag_definition` / `asset_template_tag` / `asset_tag`

## 三表怎么协作

```text
tag_definitions          全局「有哪些标签」（展示名、输入控件类型）
        ▲
        │ tag_key（字符串，非 FK）
        │
asset_template_tags      某种 template_type 允许/排序哪些标签
        │
        ▼（导入过滤）
asset_tags               某素材的具体值
```

`template_type` 常见值：`image`、`video`、`audio`、`home_featured`（首页精选返回哪些标签也走模板）。

## 导入时标签流水线

```text
metadata dict（exifread / ffmpeg）
  → MetadataTagMapper.map_metadata_to_tags
      （含 aspect_ratio 计算）
  → 可选 default_gps 覆盖 gps_*
  → TagService.batch_save_asset_tags
      1. 查模板允许的 tag_key
      2. 过滤
      3. 跳过已存在的 key（不覆盖旧值）
      4. bulk insert
      5. 若写入 location_poi → MetadataDictionaryService.upsert
```

异步地理编码成功后，会再走同一 `batch_save_asset_tags` 写入 6 个地点标签：

`location_country` / `province` / `city` / `district` / `poi` / `formatted`

## 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/tags/definitions` | 全部或按 `template_type` 过滤排序的标签元数据 |

前端应使用返回的 `tag_name` / `input_type` / `extra_info`，不要硬编码 `tag_key → 中文名`。

## 设计决策

### 为什么 tag_key 直连而不是 tag_id？

- 导入热路径少一次查定义表
- 跨资源类型复用同一语义键（如 `device_make`）
- 模板表表达「可选集合」，定义表表达「全局字典」

### 为什么已存在的 tag 不更新？

避免异步地理编码或重复导入把人工修正值冲掉。若要做「强制刷新元数据」，需要另开显式 API。

## 映射缺口（重要）

`MetadataTagMapper` 认识的 GPS 键主要是 EXIF 风格：`GPS GPSLatitude` 等。  
`VideoMetadataExtractor` 输出的是 `latitude` / `longitude` / `altitude`。

结果：视频文件若只靠自身元数据、又没有 `default_gps`，**地点标签与 geocoding 可能不会触发**。修映射或在 processor 里归一化键名，是明确扩展点。

## 依赖

```text
ingestion.AssetProcessor → Mapper + TagService
geocoding_tasks → LocationService + TagService
home/featured → AssetTemplateTag(template_type=home_featured) + AssetTag
assets/locations → MetadataDictionaryService（location_poi）
```

## 已知限制

- 标签值更新语义是「只增不改」
- 无用户自定义标签 CRUD API（定义靠 DB/初始化 SQL）
- audio 模板类型预留，音频导入未完整支持
