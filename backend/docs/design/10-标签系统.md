# 标签系统

## 职责边界

- **负责**：标签定义 CRUD；EXIF/FFmpeg 源键映射；按 **ingest 模板** 过滤后写入 `asset_tags`；用户语义标签覆盖写入
- **不负责**：地理编码本身（见 [异步任务](./15-异步任务.md)）；详情/筛选如何渲染（前端读 `/templates/resolve`）

关键文件：

- Router：[`routers/tags.py`](../../app/routers/tags.py)、[`routers/templates.py`](../../app/routers/templates.py)
- Service：`services/tags/`、`services/templates/`
- Mapper：[`services/tags/mapper.py`](../../app/services/tags/mapper.py)（规则来自 `tag_mappings`，空表时回退内置表）

## 表怎么协作

```text
tag_definitions          全局定义（source=system|user，options 在 extra_info）
        │
        ├── tag_mappings           源键 → tag_key + transform
        │
        └── template_fields ──▶ templates（kind=ingest|detail|filter|card）
                    │
                    ▼
               asset_tags           素材上的值
```

`extract_metadata` 与 `map_tags` 是导入主路径，**不是**可关任务。写入允许的键来自默认 ingest 模板。

旧表 `asset_template_tags` 仅作 ingest 模板缺失时的回退。

## 导入时标签流水线

```text
metadata dict
  → TagMappingService.list_active
  → MetadataTagMapper.map_metadata_to_tags
  → 可选 default_gps
  → TagService.batch_save_asset_tags（ingest 模板过滤，只增不改）
```

## 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/tags/definitions` | 标签元数据 |
| POST/PATCH/DELETE | `/tags/definitions` | 定义管理；系统标签不可删、不可改 key |
| GET/POST/PATCH/DELETE | `/tags/mappings` | 源键映射 |
| GET | `/templates/resolve` | 运行期解析默认模板 + 字段 |
| CRUD | `/templates`、`/templates/{id}/fields` | 后台模板与字段 |
| PUT | `/assets/{id}/tags` | 覆盖用户语义标签 |

前端展示名与控件走定义 / 模板字段，不要硬编码 `tag_key → 中文`。

## 已知限制

- 多选值仍挤在单行 `tag_value`（唯一约束未改）
- 导入写入仍「只增不改」；人工 upsert 只允许 `source=user`
- mapper 在映射表为空时回退代码表，避免未迁移库导入中断
