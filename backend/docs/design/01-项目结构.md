# 项目结构

本篇只列稳定的职责边界；具体文件以当前源码为准。

```text
backend/
├── run.py                      # 开发启动：uvicorn + 可选自动拉起 Taskiq Worker
├── start_worker.sh             # 生产/独立 Worker 启动脚本（默认 4 workers）
├── requirements.txt            # 运行时依赖
├── requirements-dev.txt        # 测试/开发依赖
├── scripts/
│   └── init_db.py              # 数据库初始化相关脚本入口
├── tests/                      # pytest（unit / integration）
├── docs/
│   └── design/                 # 本内部设计文档目录
└── app/
    ├── main.py                 # FastAPI 应用：中间件、静态挂载、异常、include_router
    ├── db.py                   # Engine / SessionLocal / Base / get_db
    ├── config/
    │   ├── __init__.py         # 导出 settings
    │   └── config.py           # pydantic-settings
    ├── model/                  # ORM 模型（禁止 ForeignKey / relationship）
    ├── schema/                 # Pydantic：ApiResponse + 业务 DTO
    │   ├── common.py
    │   ├── home/
    │   └── ingestion/
    ├── routers/                # APIRouter 聚合
    │   ├── assets.py
    │   ├── albums.py
    │   ├── notes.py
    │   ├── tags.py
    │   ├── management.py
    │   ├── map.py
    │   ├── home/               # featured + timeline → home_router
    │   └── ingestion/          # scan + upload → ingestion_router
    ├── services/               # 业务逻辑
    │   ├── ingestion/          # 导入编排
    │   ├── scanning/           # 文件系统扫描
    │   ├── metadata/           # 元数据提取工厂
    │   ├── thumbnail/          # 缩略图工厂
    │   ├── preview/            # 预览图（HEIC 等）
    │   ├── tags/               # 标签服务 + 映射器
    │   ├── asset.py / album.py / note.py
    │   ├── location.py         # 逆地理编码 Provider
    │   ├── asset_url.py        # 对外 URL 策略
    │   └── metadata_dictionary.py
    ├── tasks/                  # Taskiq 任务与发送器
    └── tools/                  # 无业务状态的纯工具
```

## 运行边界

| 入口 | 运行时 | 说明 |
|---|---|---|
| `backend/run.py` | Python + uvicorn | 开发主路径；可自动 `taskiq worker` |
| `app.main:app` | FastAPI | 被 uvicorn / 容器直接加载 |
| `app.tasks.broker:broker` | Taskiq Worker | 消费 `lumiharbor_tasks` 队列 |
| `backend/start_worker.sh` | bash + taskiq | 独立 Worker，适合生产分离部署 |

## 代码该放哪

| 变更类型 | 应落入 |
|---|---|
| 新 HTTP 端点 | `routers/<domain>.py`，复杂逻辑下沉 `services/` |
| 新表字段 / 新表 | `model/`，并同步仓库根 `scripts/init_db.sql`（项目约定） |
| 请求/响应形状 | `schema/` |
| 导入流水线步骤 | `services/ingestion/` 或 media 子包，不要塞进 router |
| 耗时 I/O（网络/重算） | `tasks/` + 必要时 `task_logs` |
| 无 DB 的算法 | `tools/` |
| 配置项 | `config/config.py` + `.env` |

不要在 Router 里堆积多步事务编排，也不要在 `tools/` 里依赖 FastAPI `Request` 或 Session 生命周期。
