# 横切约定

这些规则横切所有业务模块。半年后再看代码时，先确认这里有没有变。

## 1. 统一 API 响应

定义：[`app/schema/common.py`](../../app/schema/common.py)

```json
{ "code": "0", "message": "success", "result": { } }
```

| 字段 | 约定 |
|---|---|
| `code` | 字符串；`"0"` 成功，其它为错误码（HTTP 异常时常为状态码字符串） |
| `message` | 成功默认 `"success"`；失败为可读错误 |
| `result` | 成功时为业务数据；失败时为 `null` |

工厂方法：

- `ApiResponse.success(data, message="success")`
- `ApiResponse.error(code, message)`

前端 Axios 拦截器会在 `code === "0"` 时解包 `result`。因此后端新增接口应继续使用该壳，除非文档明确标注例外。

### 已知例外

| 接口 | 实际返回 | 说明 |
|---|---|---|
| `GET /home/featured` | 直接返回 `FeaturedResponse` | 无 `code/message/result` 包装；改动前需同时核对前端调用 |

### 全局异常

[`app/main.py`](../../app/main.py) 将 `HTTPException` 与未捕获异常统一转成 `ApiResponse.error(...)` 的 JSON body（HTTP 状态码仍保留 4xx/5xx）。

## 2. 软删除

- 业务表统一使用 `is_deleted: BOOLEAN`，**不用** `status: tinyint`。
- 查询默认必须带 `is_deleted == False`（或等价过滤）。
- **例外（当前代码）**：
  - `users`：无 `is_deleted`
  - `task_logs`：无 `is_deleted`（任务执行日志表）

素材批量软删会级联软删关联行（相册关联、标签、收藏），详见 [素材库](./07-素材库.md)。

## 3. 禁止数据库外键

- ORM **不声明** `ForeignKey` / `relationship`。
- 表间用 `BIGINT` ID 或 `tag_key` 字符串在应用层关联。
- 一致性由 Service 校验（例如封面素材是否存在、笔记封面是否有效）。

**为什么**：个人项目迭代快，避免迁移时外键阻塞；用索引保证查询性能即可。

## 4. 用户身份（当前阶段）

| 现状 | 说明 |
|---|---|
| 无登录/注册路由 | `User` 模型存在但未接入鉴权链路 |
| 调用方式 | 多数接口用 Query `user_id`（默认 `1`），或代码内 `current_user_id = 1` |

写新接口时：继续显式接收 `user_id`/`created_by`，并在注释或 TODO 中保留「未来接认证中间件」的入口，不要假装已经鉴权。

## 5. 媒体路径与 URL

| 层 | 约定 |
|---|---|
| 数据库 | 存相对 `NAS_DATA_PATH` 的路径（`original_path` / `thumbnail_path` / `preview_path`） |
| 静态挂载 | `main.py` 将 NAS 目录挂到 `MEDIA_BASE_PATH`（默认 `/media`），**当前不鉴权** |
| API 输出 | 通过 `AssetUrlProviderFactory` 生成 `*_url` 字段 |

策略实现见 [`app/services/asset_url.py`](../../app/services/asset_url.py)：

- `ASSET_URL_PROVIDER=local` → `{PUBLIC_BASE_URL}{MEDIA_BASE_PATH}/{relative}`
- `ASSET_URL_PROVIDER=oss` → `{OSS_PUBLIC_BASE_URL}/{key}`（预留）

## 6. CORS

当前按**局域网私有部署**放开：`allow_origins=["*"]`（`allow_credentials=False`，与通配 Origin 互斥）。配置在 [`main.py`](../../app/main.py)。若以后上公网，应收紧 Origin 白名单。

## 7. 数据库会话

- 依赖注入：`Depends(get_db)`（[`app/db.py`](../../app/db.py)）
- 连接池：`pool_pre_ping=True`，`pool_recycle=3600`
- 会话时区：`SET time_zone = '{DB_TIMEZONE}'`（默认 `+08:00`）

## 8. 分层依赖方向

```text
routers → services → model / tools / tasks
                ↘ schema（类型边界）
```

允许：Service 调用其它 Service（如导入调用相册）。  
避免：tools 依赖 routers；tasks 直接操作 HTTP 响应对象。
