# 素材库

路由：

- 列表 [`app/(main)/assets/page.tsx`](../../app/(main)/assets/page.tsx)
- 详情 [`app/(main)/assets/[id]/page.tsx`](../../app/(main)/assets/[id]/page.tsx)

## 职责边界

- **负责**：筛选浏览、无限滚动瀑布流、批量选择删除、本地上传（附可选 GPS）、单素材详情/标签/收藏/相似推荐
- **不负责**：文件夹扫描导入（相册「从文件夹导入」）；标签定义后台在 `/settings`

## 列表页能力

| 能力 | 实现 |
|---|---|
| 瀑布流 | [`AssetGrid`](../../components/assets/AssetGrid.tsx) → [`AssetMasonry`](../../components/assets/AssetMasonry.tsx) |
| 筛选栏 | [`AssetFilterBar`](../../components/assets/AssetFilterBar.tsx)：字段来自 `GET /templates/resolve?kind=filter`；默认仍是日期 / 地点 / 收藏 |
| 上传 | hidden `<input type="file">` → [`UploadAssetsModal`](../../components/assets/UploadAssetsModal.tsx) → `ingestionApi.uploadAssets` |
| 批量模式 | 多选 → `assetsApi.deleteAssets` |
| 卡片 | [`AssetCard`](../../components/assets/AssetCard.tsx) + [`FavoriteButton`](../../components/assets/FavoriteButton.tsx) |

### 筛选模型

`AssetsFilter`（[`lib/api/assets.ts`](../../lib/api/assets.ts)）：

- `asset_type` / `location` / `location_poi`
- `shot_at_start` / `shot_at_end`
- `is_favorited`
- `sort_by` / `sort_order`（API 支持；当前 FilterBar 未暴露全部排序 UI）

地点选项来自 `GET /assets/locations`（Query `staleTime` 5 分钟）。

### 瀑布流与分页

```text
AssetGrid
  useQuery(['assets', page, pageSize, filter])
  pageSize = 30
  useInfiniteScroll(threshold=500) → page++
  累积 allAssets → AssetMasonry
```

`AssetMasonry`：**最短列优先**分配，用 `aspect_ratio` 估高；断点随视口列数变化（实现见组件内）。相册详情复用同一组件。

列表页使用 [`AssetFilterBar`](../../components/assets/AssetFilterBar.tsx)；改筛选优先改 FilterBar。

## 上传数据流

```text
选文件 → UploadAssetsModal
  ├─ 可选 MapPicker（高德）产出 LocationData
  └─ ingestionApi.uploadAssets(files, locationData)
        POST /ingestion/upload/batch  (multipart)
          FormData: files[]
                   + default_gps / location_poi（可选）
        → invalidateQueries(['assets'])
```

上传依赖 `NEXT_PUBLIC_AMAP_*`（仅选点时）；不选点也可上传。

## 详情页能力

[`assets/[id]/page.tsx`](../../app/(main)/assets/[id]/page.tsx)：

| 区块 | API |
|---|---|
| 主媒体 | `getAsset`；显示 URL 优先 preview → original → thumbnail |
| 元数据 / 标签 | `GET /templates/resolve?kind=detail` + `getAssetTags`；用户标签可编辑 |
| 收藏切换 | `favorite` / `unfavorite` |
| 相似推荐 | `getSimilarAssets`（视觉距离 + 同日/同地/同相册加权） |
| 大图查看 | [`ImageViewer`](../../components/assets/ImageViewer.tsx) |

标签展示约定：UI 用定义表里的中文名，**不要**在前端硬编码 `tag_key → 中文` 映射。

## 数据流总览

```text
/assets page
  ├─ locations query → GET /assets/locations
  ├─ AssetGrid → GET /assets?...
  ├─ upload → POST /ingestion/upload/batch
  └─ batch delete → POST /assets/batch-delete

/assets/:id
  ├─ GET /assets/{id}
  ├─ GET /assets/{id}/tags
  ├─ GET /tags/definitions（经 hook + localStorage）
  ├─ POST|DELETE /assets/{id}/favorite
  └─ GET /assets/{id}/similar
```

## 设计决策

### 为什么列表自管累积分页而不是用 `useInfiniteQuery`？

现有 `AssetGrid` 用 page state + `useInfiniteScroll` 手写累积，逻辑直观且已与筛选重置耦合。若大改可迁到 `useInfiniteQuery`，但需保留「筛选变化清空列表」语义。

### 为什么上传走 ingestion 而不是 assets？

后端导入主链路在 ingestion（哈希、缩略图、异步任务）；前端只负责选文件与可选默认 GPS。

## 与文档差异

- `CLAUDE.md` 筛选写「类型 + 8 城 + 多标签 + AI 评分排序」—— **当前 FilterBar 是日期/地点/收藏**；无 AI 评分排序 UI。
- 已具备详情页、相似推荐、上传、批量删除（旧文档未完整描述）。

## 已知限制

- Axios 默认 timeout 10s，大批量上传可能失败。
- `assetsApi.getTags` 未接线到 UI。
- 批量删除失败用 `window.alert`，与其它页 sonner toast 不一致。
- `export const dynamic = 'force-dynamic'` 写在 client page 上，对 App Router 的实际影响有限（以 Next 行为为准）。
