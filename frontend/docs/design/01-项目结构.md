## 运行边界

| 入口 | 运行时 | 说明 |
|---|---|---|
| `npm run dev` | Next.js dev server | 默认 `http://localhost:3000` |
| `npm run build` | `next build --webpack` | 含类型检查的生产构建 |
| `npm run start` | Next.js production | 需先 build |
| `app/api/generate` | Next Route Handler | 仅服务 Novel AI；读 `OPENAI_API_KEY` |

浏览器业务 API 一律打到 `NEXT_PUBLIC_API_URL`（默认 `http://localhost:8000`），**无全局 `/api` 前缀**。

## 代码该放哪

| 变更类型 | 应落入 |
|---|---|
| 新页面路由 | `app/(main)/<domain>/page.tsx`，复杂 UI 下沉 `components/` |
| 新后端调用 | `lib/api/<domain>.ts`，共享类型放 `lib/api/types.ts` 或同文件导出 |
| 跨页复用 UI | `components/common/` |
| 领域专用 UI | `components/<domain>/` |
| 服务端状态策略 | 页面/组件内 `useQuery`；全局默认改 `providers.tsx` |
| 纯工具（无 React） | `lib/utils/` |
| 可复用交互 Hook | `lib/hooks/` |
| Next 服务端能力（密钥、流式） | `app/api/**/route.ts`，不要把密钥塞进客户端组件 |

不要在 `page.tsx` 里堆积大段 JSX 与 HTTP 细节；也不要在组件里直接 `axios.create` 绕过 `apiClient`（除非有文档化的例外理由）。
