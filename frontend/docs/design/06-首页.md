## 数据流

```text
HomePage
  ├─ DomeGalleryContainer
  │     useQuery(['featured-assets-dome', loadedCount])
  │       → homeApi.getFeatured(loadedCount)
  │       → /home/featured?user_id=1&limit=N
  │
  ├─ MapView3D
  │     useQuery(['locations'])
  │       → homeApi.getLocations()  // Mock，不打网
  │
  └─ Timeline
        useQuery(['timeline'])
          → homeApi.getTimeline(10)
          → /home/timeline?limit=10&created_by=1
```

## 设计决策

### 为什么精选墙从 Bento 换成 Dome Gallery？

Dome 适合展示更多收藏（可滚到 150），视觉冲击更强；Bento 固定 9 格更像仪表盘。工具函数 `bento.ts` 可留作将来网格布局复用。

### 为什么首页地球仍用 Mock？

独立 `/map` 已接真实足迹聚合；首页区块尚未切换到 `mapApi`，避免与全屏地图页的交互模型冲突。后续可直接改 `MapView3D` 的 queryFn，或链到 `/map`。

- Dome 最大 150 与后端 featured `limit` 上限应对齐（见后端首页文档）。
