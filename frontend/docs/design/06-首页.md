# 首页

路由：[`app/(main)/page.tsx`](../../app/(main)/page.tsx)

## 职责边界

- **负责**：品牌标题、精选收藏墙、足迹入口、笔记时间轴
- **不负责**：独立足迹地图全屏交互（见 [地图足迹](./12-地图足迹.md)）；素材收藏写入（在素材库）

## 区域结构

```text
ParticleBackground（仅首页，暖色低量粒子）

section 1  精选时光
  BlurText「拾光坞」+ TextType 轮播（产品既定文案）
  DomeGalleryContainer → homeApi.getFeatured

section 2  足迹入口（非内嵌地球）
  文案 + Link → /map（真实足迹）

section 3  笔记时间轴
  Timeline (dynamic) → homeApi.getTimeline
```

首页不再内嵌 Mock 3D 地球，避免与 `/map` 双栈噪音；`MapView3D` / `Globe3D` 仍可被 `/map` 或其它入口复用，首页不再 dynamic 加载。

## 1. 精选照片墙（Dome Gallery）

| 项 | 现状 |
|---|---|
| 组件 | [`DomeGalleryContainer`](../../components/home/DomeGalleryContainer.tsx) + [`DomeGallery`](../../components/home/DomeGallery.tsx) |
| 数据 | `GET /home/featured`（真实；**无 ApiResponse 壳**） |
| 语义 | 用户**收藏**素材 |
| 加载 / 空态 | `MasonrySkeleton` / `EmptyState`（去素材库收藏、手机快传） |

## 2. 足迹入口

轻量 CTA，不再拉 Mock locations、不再挂 R3F Canvas。完整浏览走 `/map`。

## 3. 笔记时间轴

| 项 | 现状 |
|---|---|
| 组件 | [`Timeline`](../../components/home/Timeline.tsx) + [`TimelineEvent`](../../components/home/TimelineEvent.tsx) |
| 数据 | `GET /home/timeline`（真实） |
| 分组 | 按 `createdAt` 年份 |
| 高度 | 内容驱动，不再 `min-h-screen` 硬凑满屏 |

## 数据流

```text
HomePage
  ├─ DomeGalleryContainer → homeApi.getFeatured
  ├─ Link /map
  └─ Timeline → homeApi.getTimeline(10)
```

## 设计决策

### 为什么首页去掉内嵌地球？

Mock 地球与 `/map` 真数据分裂，且叠粒子 + Dome + R3F 首屏过重。入口文案足够导向真实地图页。

### 首页 / 列表副文案

产品既定文案（如 TextType 三句、素材/相册/笔记页副标题）**不要擅自改写**；布局与视觉可动，文案以源码当前字符串为准。

## 已知限制

- featured 无壳响应依赖拦截器「非标准格式原样通过」。
- Dome 最大 150 与后端 featured `limit` 上限应对齐。
- 首页未展示足迹预览数字（需要时可接 `mapApi.getStatistics` 轻量条）。
