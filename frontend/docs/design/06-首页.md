# 首页

路由：[`app/(main)/page.tsx`](../../app/(main)/page.tsx)

## 职责边界

- **负责**：品牌标题、精选收藏墙、足迹整体预览（弱交互）、笔记时间轴
- **不负责**：足迹全屏交互与详情抽屉（见 [地图足迹](./12-地图足迹.md)）；素材收藏写入（在素材库）

## 区域结构

```text
ParticleBackground（仅首页，暖色低量粒子）

section 1  精选时光
  BlurText「拾光坞」+ TextType 轮播（产品既定文案）
  DomeGalleryContainer → homeApi.getFeatured

section 2  足迹地图预览
  HomeFootprintPreview（dynamic）
    标题「足迹地图」+「打开地图」→ /map
    视口内再挂高德 preview + mapApi.getFootprints
    点击足迹点 → /map?fp={id}

section 3  笔记时间轴
  Timeline (dynamic) → homeApi.getTimeline
```

首页不再内嵌 Mock 3D 地球；真实轨迹与 `/map` 同源（高德 2D `macaron`）。完整拖拽/滚轮/详情抽屉只在 `/map`。

## 1. 精选照片墙（Dome Gallery）

| 项 | 现状 |
|---|---|
| 组件 | [`DomeGalleryContainer`](../../components/home/DomeGalleryContainer.tsx) + [`DomeGallery`](../../components/home/DomeGallery.tsx) |
| 数据 | `GET /home/featured`（真实；**无 ApiResponse 壳**） |
| 语义 | 用户**收藏**素材 |
| 加载 / 空态 | `MasonrySkeleton` / `EmptyState`（去素材库收藏、手机快传） |

## 2. 足迹地图预览

| 项 | 现状 |
|---|---|
| 组件 | [`HomeFootprintPreview`](../../components/home/HomeFootprintPreview.tsx) |
| 底图 | [`Amap2DMap`](../../components/map/Amap2DMap.tsx) `variant="preview"` |
| 数据 | `mapApi.getFootprints`（`queryKey: ['footprints']`，与 `/map` 共享缓存） |
| 加载策略 | IntersectionObserver（`rootMargin` 约 240px）后再请求与挂 SDK；组件本身 `dynamic` |
| 交互 | 可平移；**禁用滚轮缩放**（避免抢页面滚动）；无详情抽屉；点 → `/map?fp=` |
| 尺寸 | 地图区约 `min(68vh, 640px)`，最小高度 420px |
| 空态 | 无 GPS 足迹时简短引导 |

文案仍为产品既定：「足迹地图」「探索你走过的每一个角落」「打开地图」。

## 数据流

```text
HomePage
  ├─ DomeGalleryContainer → homeApi.getFeatured
  ├─ HomeFootprintPreview（进视口后）
  │    └─ mapApi.getFootprints → Amap2DMap preview
  └─ Timeline → homeApi.getTimeline(10)
```

## 设计决策

### 为什么首页嵌预览而不是全屏地图？

要一眼看到整体轨迹，但详情/强交互仍归 `/map`，避免首页再挂抽屉与抢滚轮。Mock 3D 地球已否决（与真数据分裂且过重）。

### 为什么视口内再加载？

首页已有粒子 + Dome；高德 SDK 延后到接近足迹区再挂，减轻首屏主线程压力。

### 首页 / 列表副文案

产品既定文案（如 TextType 三句、素材/相册/笔记页副标题）**不要擅自改写**；布局与视觉可动，文案以源码当前字符串为准。

## 已知限制

- featured 无壳响应依赖拦截器「非标准格式原样通过」。
- Dome 最大 150 与后端 featured `limit` 上限应对齐。
- 预览区未展示 `mapApi.getStatistics` 数字条（需要时可加轻量条）。
