# 应用入口与配置

## 职责边界

| 文件 | 职责 |
|---|---|
| [`app/layout.tsx`](../../app/layout.tsx) | HTML 壳、metadata/favicon、粒子背景、挂载 Providers |
| [`app/providers.tsx`](../../app/providers.tsx) | TanStack Query + Sonner |
| [`app/(main)/layout.tsx`](../../app/(main)/layout.tsx) | 主区域 + 右侧 Dock |
| [`next.config.mjs`](../../next.config.mjs) | 远程图片白名单、`transpilePackages: ['three']` |
| [`tailwind.config.ts`](../../tailwind.config.ts) | 设计 token、插件 |
| [`.env.template`](../../.env.template) | 可提交的环境变量清单 |
| `.env` | 本地实际值（勿提交密钥到文档/仓库） |

## 启动数据流

```text
npm run dev
  │
  ├─ 加载 .env / .env.local（Next 约定）
  ├─ 编译 App Router
  └─ http://localhost:3000
         │
         ├─ app/layout.tsx
         │     ├─ ParticleBackground（ogl WebGL）
         │     └─ Providers → QueryClient + Toaster
         └─ app/(main)/layout.tsx
               ├─ 页面 children
               └─ DockNavigation
```

生产：`npm run build`（脚本为 `next build --webpack`）→ `npm run start`。

## 根布局做了什么

1. 设置 `metadata`：标题「LumiHarbor - 拾光坞」、描述、SVG icon
2. `<html lang="zh-CN">` + `body` 基类（`font-sans antialiased bg-background`）
3. 全屏粒子背景（固定层，不挡交互）
4. 包裹 `Providers`

`(main)/layout` **只**挂 Dock，**不再**挂 Spotlight（组件已删除）。

## 关键配置项

| 变量 | 出现位置 | 影响 |
|---|---|---|
| `NEXT_PUBLIC_API_URL` | `client.ts`、部分组件 / `mediaUrl` | Axios baseURL；相对媒体路径拼接。默认 `http://localhost:8000` |
| `NEXT_PUBLIC_AMAP_KEY` | `MapPicker` | 上传/导入时选点（高德 JSAPI） |
| `NEXT_PUBLIC_AMAP_SECURITY_CODE` | `MapPicker` | 高德安全密钥 |
| `NEXT_PUBLIC_MAPBOX_TOKEN` | `Mapbox2DMap` | `/map` 2D 视图；需 `pk.*` Public Token |
| `OPENAI_API_KEY` | `app/api/generate/route.ts`（仅服务端） | Novel Ask AI；**不要**加 `NEXT_PUBLIC_` |

### 模板缺口

[`.env.template`](../../.env.template) 目前列出高德 / OpenAI / Mapbox，**未列出** `NEXT_PUBLIC_API_URL`。本地仍应配置该项（见 `frontend/README.md` 或直接依赖默认值）。

## Next 配置要点

[`next.config.mjs`](../../next.config.mjs)：

- `images.remotePatterns`：允许 `picsum.photos`（历史 Mock/占位）与 `localhost`
- `transpilePackages: ['three']`：保证 R3F / three 在 bundler 下可用

业务媒体多数用 `<img>` / Mapbox / R3F 纹理，而非全面接入 `next/image` 优化链路。

## Tailwind 要点

- `content` 包含 `streamdown` 包路径，避免 Markdown 样式被 purge
- 插件：`tailwindcss-animate`、`@tailwindcss/typography`（Novel prose）
- 颜色语义：`background` / `foreground` / `primary` / `accent-*`

全局样式还引入 KaTeX 与 `styles/prosemirror.css`（数学公式与编辑器）。

## 设计决策

### 为什么根布局就挂粒子背景？

全站氛围统一，避免每个页面重复挂载 WebGL；用 ogl 轻量实现，失败不影响主内容（组件自身管理 canvas）。

### 为什么 AI Key 走 Next Route Handler？

浏览器不能持有 OpenAI 密钥。Novel 气泡菜单打同源 `/api/generate`，由服务端读 `OPENAI_API_KEY` 再流式转发。

## 已知限制

- 无应用级错误边界页（`error.tsx` / `global-error.tsx`）与 loading UI 约定文件；各页自行处理 `isLoading` / `isError`。
- 401 跳转 `/login`，但登录路由未实现。
- `frontend/README.md` 仍写 Next 14 / Framer Motion / Zustand 使用中，与当前依赖和源码不一致——以本目录为准。
