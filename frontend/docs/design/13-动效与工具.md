# 动效与工具

## 职责边界

- **负责**：可复用动效预设与 Hook、媒体 URL 拼接、类名合并
- **不负责**：业务 API；页面级编排

## GSAP

| 位置 | 用途 |
|---|---|
| [`lib/utils/gsap.ts`](../../lib/utils/gsap.ts) | `hoverScale` / `tapScale` / `fadeIn` 预设 |
| [`lib/hooks/useGsapPressableScale.ts`](../../lib/hooks/useGsapPressableScale.ts) | 按钮 hover/press 缩放 handlers |
| [`DockNavigation`](../../components/layout/DockNavigation.tsx) | Dock 滑入、按钮、tooltip、指示器 |
| 卡片等 | 各组件内直接 `gsap.to`（未全部收敛到 hook） |

交互缩放优先复用 `useGsapPressableScale`，避免每个按钮复制四套 handler。

## 媒体 URL

[`lib/utils/mediaUrl.ts`](../../lib/utils/mediaUrl.ts)：

```text
resolveMediaUrl(url?, path?)
  1. 非空 url → 直接用
  2. path 已是 http(s) → 直接用
  3. 否则 NEXT_PUBLIC_API_URL + '/' + path
```

素材详情页内另有同名本地函数（逻辑等价）；长期应统一引用 `lib/utils/mediaUrl`，避免分叉。

WGS84 → GCJ-02 在 [`lib/utils/coord.ts`](../../lib/utils/coord.ts)，供高德地图使用。

## 设计决策

### 为什么动效工具与业务 hooks 分开放？

`lib/utils` 保持无 React（或仅类型）；`lib/hooks` 承载 React 生命周期。GSAP 预设放 utils，绑定 ref 的逻辑放 hooks。

## 已知限制

- 详情页重复实现 `resolveMediaUrl`。
- Dock 快捷键仅展示，未接入本篇「工具」层的全局 keybinding。
