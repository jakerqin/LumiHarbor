# 地图足迹

路由：[`app/(main)/map/page.tsx`](../../app/(main)/map/page.tsx)

## 职责边界

- **负责**：全屏 2D 足迹浏览、点击足迹看该点照片、展示统计
- **不负责**：3D 地球；笔记挂足迹；逆地理编码（后端 geocoding 写 `location_*`）

关键组件：

| 文件 | 职责 |
|---|---|
| [`Amap2DMap`](../../components/map/Amap2DMap.tsx) | 高德 `macaron` 底图；按 `first_shot_at` 排序后第一点为青绿「起点」（更大）；折线 `showDir` 示方向；点旁分行日期+地点 |
| [`FootprintDetail`](../../components/map/FootprintDetail.tsx) | 选中足迹详情抽屉（暖色不透明面板；照片可进素材页） |
| [`MapStatistics`](../../components/map/MapStatistics.tsx) | 顶部统计条（浅色底上用不透明暖色面板） |
| [`lib/utils/coord.ts`](../../lib/utils/coord.ts) | WGS84 → GCJ-02（高德展示） |

已删除：`Mapbox2DMap`、`Globe3DMap` / 3D 标记连线；npm 已卸 `mapbox-gl` / `react-map-gl`。

## 底图与坐标系

```text
API / DB：素材 GPS 为 WGS84（EXIF）
高德底图：GCJ-02
展示前：wgs84ToGcj02(lng, lat) 再 Marker / Polyline
```

环境变量（与上传 `MapPicker` 共用）：

- `NEXT_PUBLIC_AMAP_KEY`
- `NEXT_PUBLIC_AMAP_SECURITY_CODE`

不再需要 `NEXT_PUBLIC_MAPBOX_TOKEN`。

## 数据流

```text
MapPage
  ├─ useQuery(['footprints']) → mapApi.getFootprints()
  ├─ useQuery(['map-statistics'], staleTime=1h) → mapApi.getStatistics()
  └─ 点击足迹 → selectedFootprintId
        └─ FootprintDetail → mapApi.getFootprintDetail(id)
              └─ 缩略图 → /assets/{id}
```

后端网格聚合（约 0.01°）见 [`backend/docs/design/12-地图足迹.md`](../../../backend/docs/design/12-地图足迹.md)。

## 设计决策

### 为什么用高德而不是 Mapbox？

Mapbox 经典暗色样式默认偏英文标注；虽可用 `language: zh-Hans`，国内路网/POI 与合规观感仍弱于高德。项目上传选点已接高德，足迹页复用同一 Key，中文为一等能力。

### 为什么不做 3D / 笔记挂点？

3D 演示成本高、可读性差；笔记尚无稳定地点模型，产品未定前不绑足迹。

## 已知限制

- 无日期筛选 UI（API 支持 `start_date` / `end_date`）。
- 境外点不做 GCJ 偏移（粗判国境后原样）。
- 地点名依赖后端 `location_*` 标签，与高德底图注记可能不完全一致。
