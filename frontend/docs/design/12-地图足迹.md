# 地图足迹

路由：[`app/(main)/map/page.tsx`](../../app/(main)/map/page.tsx)

## 职责边界

- **负责**：全屏足迹浏览（3D / 2D 切换）、点击足迹看详情、展示统计
- **不负责**：逆地理编码；首页内嵌地球的 Mock 数据（见 [首页](./06-首页.md)）

关键组件：

| 文件 | 职责 |
|---|---|
| [`Globe3DMap`](../../components/map/Globe3DMap.tsx) | R3F 3D 地球 + 足迹标记/连线 |
| [`FootprintMarker3D`](../../components/map/FootprintMarker3D.tsx) | 3D 标记 |

| [`lib/utils/geo.ts`](../../lib/utils/geo.ts) | lat/lng ↔ 球面坐标、弧线 |

## 视图模式

```text
viewMode: '3d' | '2d'   （默认 3d）

3d → <Canvas> + Globe3DMap(footprints)
2d → Mapbox2DMap(footprints)   // 需 NEXT_PUBLIC_MAPBOX_TOKEN
```

未配置 Mapbox token 时，2D 视图显示配置提示（见组件内文案；文案写 `.env.local`，实际也可写 `.env`）。

## 数据流

```text
MapPage
  ├─ useQuery(['footprints']) → mapApi.getFootprints()
  │     GET /map/footprints?user_id=1
  ├─ useQuery(['map-statistics'], staleTime=1h) → mapApi.getStatistics()
  │     GET /map/statistics?user_id=1
  └─ 点击足迹 → selectedFootprintId
        └─ FootprintDetail
              → mapApi.getFootprintDetail(id)
              GET /map/footprints/{id}?user_id=1
```

类型见 [`lib/api/types.ts`](../../lib/api/types.ts)：`Footprint`、`FootprintDetail`、`MapStatistics`。

后端聚合策略（网格约 0.01°）见 `backend/docs/design/地图足迹.md`。

## 与首页地球的关系

| | `/map` | 首页 `MapView3D` |
|---|---|---|
| API | `mapApi` 真实 | `homeApi.getLocations` **Mock** |

两套 3D 实现并存；改足迹可视化时先确认用户场景是「首页区块」还是「地图页」。

## 设计决策

### 为什么独立 `/map` 而不是只做首页区块？

全屏交互（切换 2D、点选详情、统计）需要独立信息架构；首页保留轻量预览（即便当前仍是 Mock）。Dock 已加入「地图」入口。

### 为什么 3D 用 R3F、2D 用 Mapbox？

3D 强调「世界尺度」氛围；2D 便于城市级缩放与熟悉的地图操作。Mapbox 需要公网 token；3D 地球纹理不依赖 Mapbox。
