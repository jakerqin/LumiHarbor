# 前端架构总览

LumiHarbor（拾光坞）前端是一个 **Next.js App Router + React 19 + TanStack Query + Axios** 的个人生活素材管理界面。它负责素材浏览/上传、相册、笔记（Novel/Tiptap）、首页聚合展示，以及独立的地图足迹页。

三条事实值得先记住：

- **页面是薄编排层**。`app/(main)/**/page.tsx` 管路由参数、Query 与 Modal；展示与领域交互落在 `components/`；HTTP 契约统一收敛到 `lib/api/`。
- **服务端状态走 TanStack Query**。默认 `staleTime=0`（回页即拉新）；标签定义等少数查询单独加长缓存。Zustand 虽在依赖里，**当前源码未使用**。
- **Axios 拦截器自动解包 `ApiResponse`**。业务代码读 `response.data` 即业务 `result`；`GET /home/featured` 是已知例外（直接返回业务对象，拦截器原样放行）。

## 分层怎么分工

```text
next dev / next start
    └── app/
            ├── layout.tsx              根布局：元数据、粒子背景、Providers
            ├── providers.tsx           QueryClient + Sonner Toaster
            ├── globals.css             深色主题与全局样式
            ├── api/generate/route.ts   Next 服务端：Novel AI 流式生成
            └── (main)/                 主应用路由组
                    ├── layout.tsx      Dock 导航
                    ├── page.tsx        首页
                    ├── assets/         素材库 + 详情
                    ├── albums/         相册列表 + 详情
                    ├── notes/          笔记列表 / 新建 / 详情编辑
                    ├── map/            足迹地图（高德中文 2D）
                    └── mobile-upload/  局域网手机上传（移动端优先，桌面也可打开）
            │
            ├── components/             UI 与领域组件（按模块分目录）
            ├── lib/
            │   ├── api/                Axios 客户端 + 各域 API + 类型
            │   ├── hooks/              无限滚动、GSAP、标签定义缓存
            │   ├── markdown/           asset:// 协议（遗留/备用）
            │   └── utils/              cn、mediaUrl、geo、gsap 预设等
            └── styles/                 ProseMirror / Novel 样式
```

## 一条典型页面请求经过什么

```text
浏览器路由 /assets
        │
        ▼
app/(main)/assets/page.tsx
  ├─ 本地 UI 状态（filter / batch / upload modal）
  └─ 子组件 AssetGrid
        │
        ▼
useQuery(['assets', page, filter])
        │
        ▼
assetsApi.getAssets(...)
        │
        ▼
apiClient (Axios)
  ├─ request：可选 Bearer token（localStorage）
  └─ response：若命中 {code,message,result} 且 code==="0" → data=result
        │
        ▼
NEXT_PUBLIC_API_URL → FastAPI /assets
        │
        ▼
组件渲染 AssetMasonry（最短列优先瀑布流）
```

笔记写路径额外多一步：Novel 编辑器产出 Tiptap `JSONContent`，前端用 `jsonToMarkdown` 生成可选 Markdown 副本，一并 `POST/PATCH /notes`。

## 与产品文档的关系

- `CLAUDE.md` / `AGENTS.md` / `frontend/README.md` 面向协作与快速上手，会滞后于代码。
- **本目录以当前 `frontend/` 源码为准**。已知与旧文档不一致之处，已写进各模块「已知限制 / 与文档差异」小节。
- 后端契约细节以 `backend/docs/design/` 为准；本目录关注前端边界、数据流与接线状态。
