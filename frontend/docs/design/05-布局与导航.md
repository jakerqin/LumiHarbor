# 布局与导航

## 职责边界

- **负责**：全站壳层视觉（粒子背景）、主路由组布局、右侧 Dock 导航与活动指示
- **不负责**：各业务页内容；全局搜索（已移除）

## 布局结构

```text
<html>
  <body>
    ParticleBackground          ← fixed 全屏 WebGL（ogl）
    Providers
      └── (main) layout
            ├── {children}      ← 各业务页
            └── DockNavigation  ← fixed 右侧，默认收起
```

`(main)` 覆盖路由：`/`、`/assets`、`/assets/[id]`、`/albums`、`/albums/[id]`、`/notes`、`/notes/new`、`/notes/[id]`、`/map`。

**当前 Dock 没有**「标签 / 设置 / 关于」入口；也没有独立 tags/settings 页面。

## Dock 行为

导航项（源码常量 `dockItems`）：

| 标签 | 路径 | 快捷键提示 |
|---|---|---|
| 首页 | `/` | ⌘H |
| 素材 | `/assets` | ⌘A |
| 相册 | `/albums` | ⌘L |
| 笔记 | `/notes` | ⌘N |
| 地图 | `/map` | ⌘M |

交互要点：

1. **边缘唤出**：鼠标靠近右侧边且落在活动指示器垂直触发带内 → Dock 滑入；远离则滑出（滞后区避免抖动）。
2. **GSAP 动效**：容器 `x` 滑入/出；按钮 hover 左移 + 放大；tooltip 淡入。
3. **活动指示器**：屏幕最右侧细条，跟随当前路由对应按钮垂直位置。
4. **路径匹配**：首页精确匹配 `/`；其它前缀匹配（如 `/assets/123` 高亮「素材」）。

`handleClick` 仍保留 `action === 'search'` → `dispatchEvent('open-search')` 的分支，但 **dockItems 未配置任何 search 项**，且监听该事件的 Spotlight 组件已不存在。

## 粒子背景

[`ParticleBackground`](../../components/background/ParticleBackground.tsx) 使用 **ogl** 渲染低饱和冷色粒子，挂在根布局以统一氛围。可配置粒子数、速度、hover 位移等；默认关闭 hover 位移以降低干扰。

## 设计决策

### 为什么 Dock 默认隐藏、靠右缘唤出？

主内容（瀑布流、地图全屏、笔记编辑器）需要横向空间；常驻 Dock 会压内容。右缘细指示器保留「我在哪」的方位感。

### 为什么快捷键只显示在 Tooltip？

当前**未注册**全局 keyboard shortcut 监听；⌘H 等仅为视觉提示。若要做成真快捷键，需统一 keydown 处理并避开输入框焦点。
