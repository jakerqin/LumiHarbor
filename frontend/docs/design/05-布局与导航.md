## 布局结构

```text
<html>
  <body>
    Providers
      └── (main) layout
            ├── {children}
            ├── DockNavigation      ← md+ 右侧边缘唤出
            └── MobileBottomNav     ← <md 底栏常驻
```

列表页用 `PageShell`（`max-w-[1400px]` + 移动底栏 `pb`）与 `PageHeader`（标题 + 一句说明 + 右侧操作，标题旁不再贴大 Lucide）。

## 导航项

`MAIN_NAV` 为唯一源（Dock / 底栏共用）：

| 标签 | 路径 |
|---|---|
| 首页 | `/` |
| 素材 | `/assets` |
| 相册 | `/albums` |
| 笔记 | `/notes` |
| 地图 | `/map` |
| 设置 | `/settings`（标签 / 模板 / 任务） |
| 快传 | `/mobile-upload` |

## Dock（桌面）

1. **边缘唤出**：鼠标靠近右侧且落在指示器垂直触发带内 → 滑入；远离则滑出。
2. **GSAP**：容器 `x`；按钮 hover 左移 + 放大。
3. **活动指示器**：右侧细条跟随当前路由。
4. **`md` 以下隐藏**，改走底栏。

快捷键仅 Tooltip 展示，未注册全局 keydown。

## 移动底栏

- `md:hidden` 固定底栏，带 safe-area。
- 触屏不再依赖 `mousemove`，解决「Dock 永远不出现」。

## 粒子背景

不再挂在根布局。仅首页挂载，数量约 90、暖色低饱和，降低素材/地图/笔记页成本。

## 设计决策

### 为什么桌面仍用边缘 Dock？

主内容需要横向空间；常驻侧栏会压瀑布流与地图。

### 为什么导航抽 `navItems`？

避免 Dock 与底栏各自维护一份路径/标签，改一端漏一端。

## 已知限制

- 地图全屏时底栏会叠在地图底部（可接受；需要时可再按路由隐藏）。
