# AI 修图与生图

后端设计见 [后端 19 · AI 修图](../../../backend/docs/design/19-AI修图.md)。这里只记录前端入口、交互和数据流。

## 入口

| 入口 | 位置 | 显示条件 |
|---|---|---|
| 「AI 修图」按钮 | 素材详情页页头，「打开」左边 | `GET /ai-image/status` 的 `enabled` 为真，且素材是图片 |
| 版本条 | 详情页主图下方 | 素材有 AI 版本（原图之外至少还有一个版本） |
| 「AI 创作」 | 素材库页头的 Sparkles 图标 → `/assets/create` | `enabled` 为真；页面本身在未开启时显示引导 |
| 「AI」角标 | `AssetCard` 右上角，在类型图标左边 | `asset.ai_badge` 为 edited 或 generated |

## 组件

目录是 [`components/ai/`](../../components/ai/)：

- `AiPromptForm`：预设按钮 + 补充描述 + 「标准 / 精细」切换。修图面板和创作页共用。选中推荐精细的预设（老照片修复、上色）时，会自动切到精细档。`canSubmitPrompt` 的判断和后端 `build_prompt` 的校验一致。
- `AiEditPanel`：弹窗，按「表单 → 生成中 → 对比结果」三步走。结果页的操作有「设为当前显示」「再改一次」「不要了，删掉」三个。生成期间可以直接关掉弹窗，结果会出现在版本条里。
- `BeforeAfter`：修改前后左右并排（窄屏上下排），两张都完整显示，点图在新标签页看大图。出结果时弹窗从 `max-w-2xl` 加宽到 `max-w-5xl`。不用叠在一起拖动分界线的滑块：那样每张图都只能看到一部分，构图差别大的时候看不出效果。
- `VersionStrip`：原图 + 各 AI 版本，点击切换当前显示；可以删除版本（会弹出确认），提供「下载当前版本」。

## 数据流

```text
aiImageApi.createJob → job_id → useAiJob 每 3s 轮询（success/failed 后停止）
设为当前 / 删除版本 → 刷新 ['asset', id]、['asset-versions', id]、['assets']
   └─ 后端换掉了 thumbnail_path / preview_path，详情大图和列表缩略图都会跟着变
```

- API 在 [`lib/api/aiImage.ts`](../../lib/api/aiImage.ts)，hook 在 [`lib/hooks/useAiImage.ts`](../../lib/hooks/useAiImage.ts)（`useAiImageStatus`、`useAiJob`）。
- 发起任务时，请求会立刻返回，不受全局 10 秒超时影响；真正调用模型的过程在 Worker 里。
- 生图结果作为新素材入库。创作页展示结果后，提供「查看素材」跳转到详情页。

## 已知限制

- 关掉弹窗后，正在进行的任务不会在页面上显示进度（结果会出现在版本条里）。如果要跨页面追踪进度，需要另外做「我的任务」列表。
- 没有涂抹区域的局部修改。
- 参考图只能从素材库里选，最多 4 张。
