# 横切约定

这些规则横切所有业务模块。半年后再看代码时，先确认这里有没有变。

## 1. 统一 API 响应解包

实现：[`lib/api/client.ts`](../../lib/api/client.ts)

后端标准壳：

```json
{ "code": "0", "message": "success", "result": { } }
```

拦截器行为：

| 条件 | 行为 |
|---|---|
| 命中标准壳且 `code === "0"` | 将 `AxiosResponse.data` **替换为** `result` |
| 命中标准壳且 `code !== "0"` | `Promise.reject(ApiError)` |
| HTTP 错误且 body 是标准壳 | 同样抛 `ApiError` |
| 非标准壳（直接业务对象） | **不解包**，保持 Axios 原始 `data` |

调用侧写法：

```ts
const res = await apiClient.get<T>('/assets');
return res.data; // 已经是业务 T，不是 { result: T }
```

**禁止**再写 `response.data.result` / `response.data.data`。

### 已知例外

| 接口 | 实际返回 | 前端影响 |
|---|---|---|
| `GET /home/featured` | 直接 `FeaturedResponse`（无壳） | 拦截器原样返回；`homeApi.getFeatured` 直接读 `response.data` |

## 2. TanStack Query 默认

实现：[`app/providers.tsx`](../../app/providers.tsx)

| 选项 | 默认值 | 含义 |
|---|---|---|
| `staleTime` | `0` | 数据立刻变旧；导航回页优先重新请求 |
| `gcTime` | `10 * 60 * 1000` | 无观察者后缓存保留 10 分钟 |
| `refetchOnMount` | `true` | 挂载时按 stale 策略刷新 |
| `refetchOnWindowFocus` | `false` | 切窗不自动刷 |

需要长缓存时，在**单个 query** 上覆写，并写明原因。现有例子：

| Query | 覆写 | 原因 |
|---|---|---|
| `tag-definitions` | `staleTime` / `gcTime` = 24h + localStorage | 标签元数据几乎不变 |
| `map-statistics` | `staleTime` = 1h | 统计聚合变化慢 |
| `asset-locations` | `staleTime` = 5min | 地点列表相对静态 |

Toast：全局 `sonner` `<Toaster position="top-center" richColors />`。

## 3. 用户身份（当前阶段）

| 现状 | 说明 |
|---|---|
| 无登录/注册页 | Dock / 路由无认证流 |
| `user_id` 硬编码为 `1` | `assetsApi` / `homeApi` / `mapApi` 等 |

写新调用时：继续显式传 `user_id`（或与后端默认一致），不要假装已有会话系统。

## 4. 媒体 URL

优先使用后端返回的绝对 URL（`thumbnail_url` / `preview_url` / `original_url`）。  
若只有相对 path，用 [`resolveMediaUrl`](../../lib/utils/mediaUrl.ts) 拼到 `NEXT_PUBLIC_API_URL`。

素材详情与笔记封面对 HEIC 等格式：**优先 `preview_url`，再原图，再缩略图**。

## 5. 路径别名

`tsconfig.json`：

```json
"paths": { "@/*": ["./*"] }
```

业务导入统一写 `@/components/...`、`@/lib/...`，不要用深层相对路径穿越模块。

## 6. 主题与字体

| 项 | 约定 |
|---|---|
| 默认视觉 | 暖深色（方案 E：`background #16140f`），同色相灰阶 |
| 品牌色 | 暖米金 `primary #d4b483`，前景 `primary-foreground #1a1610`；避免紫蓝渐变 / 强 glow |
| Tailwind | `darkMode: ["class"]`，颜色与字阶 token 在 `tailwind.config.ts` |
| 字阶 | `text-page` / `text-section` / `text-card-title` / `text-meta`；`h1–h3` 在 `globals.css` 默认挂字阶 |
| 正文字体 | `font-sans` → `next/font` 注入的 Noto Sans SC（`--font-noto-sans-sc`） |
| 标题字体 | `font-heading` → Space Grotesk（`--font-space-grotesk`） |
| 等宽 | `font-mono` → Geist Mono（`--font-geist-mono`） |
| 焦点 | 全局 `:focus-visible` 用 `ring-primary` |
| 反馈 | 业务错误/校验用 `sonner` toast，禁止 `window.alert` |
| 列表壳 | `PageShell`（`max-w-[1400px]`）+ `PageHeader`；空态用 `EmptyState`；加载用 `MasonrySkeleton` |
| 玻璃态 | `.glass`（暖色半透明 + 内高光） |
| 滚动条 | 全局细条（暖米金 token `--scrollbar-*`）；下拉可挂 `.dropdown-scrollbar`（同款）；需隐藏用 `.hide-scrollbar` |

字体在 `app/layout.tsx` 用 `next/font/google` 加载；改品牌色/字体从 `layout.tsx` + `tailwind.config.ts` + `globals.css` 一起改。

**产品既定文案**（首页 TextType、各列表页副标题等）视觉重构时不要擅自改写。

## 7. 客户端组件边界

`(main)` 下绝大多数 `page.tsx` 与交互组件带 `'use client'`（Query、路由、GSAP、高德地图、遗留 Three 需要浏览器 API）。  
根 `layout.tsx` 保持 Server Component，把客户端能力下沉到 `Providers` / `ParticleBackground`。

重量级 3D / 时间轴在首页用 `next/dynamic` + `ssr: false`（地图）降低首屏成本。

## 8. 依赖方向

```text
app/pages → components → lib/api | lib/hooks | lib/utils
                ↘ app/api（仅 Novel AI 服务端）
```

允许：领域组件调用其它领域的 common（如笔记用 `AssetPickerModal`）。  
避免：`lib/api` 依赖 React 组件；工具层反向依赖页面。
